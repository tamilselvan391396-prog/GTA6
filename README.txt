SYSTEM BREACH WEBSITE — AUDIO EDITION

Included files:
- index.html: Complete website code.
- Faaa.mp3: Your supplied audio, configured to loop.

IMPORTANT:
Keep index.html and Faaa.mp3 together in the same folder (the root of your GitHub repository).
The audio starts when the visitor taps ENTER SYSTEM. It then loops across the countdown and final screen until the page is closed or the browser stops it.

Mobile browsers generally block sound that starts automatically without a user gesture. Starting it from the ENTER SYSTEM tap is the reliable approach.

GitHub Pages:
1. Extract this ZIP.
2. Upload both index.html and Faaa.mp3 to the root of your repository.
3. Replace the previous index.html if prompted.
4. Commit the changes.
5. Open your published GitHub Pages website and tap ENTER SYSTEM to start the audio.
